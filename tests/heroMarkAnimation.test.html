Homepage hero mark — clockwise fade spiral

Covers index.html's .hero-mark (the prominent homepage logo only — not the navbar/footer wordmark, which has no SVG at all) and css/pages/home/home.css's hero-mark-fade-0 through hero-mark-fade-4 keyframes: 5 real traced pieces (not the 4 a naive quadrant reading would assume — see index.html's own comment), each running a 900ms fade-out/fade-in pulse (450ms out, 450ms in) staggered 650ms from its clockwise neighbor (whole spiral: 3250ms). The next tile does NOT start fading at the current tile's trough — it starts 650ms after the current tile began, which is 200ms past that trough, so the current tile is already ~0.49 opacity into its own recovery when the handoff happens. The two tiles then share a 250ms window where the current tile finishes recovering to full opacity while the next tile fades from full down to that same ~0.49 point — a single gap continuously traveling around the mark, never an instantaneous swap, and already fully phase-aligned the instant the loop appears rather than building up tile by tile. Exactly one tile at minimum opacity at any instant, no color or glow change anywhere, fully disabled under prefers-reduced-motion.
