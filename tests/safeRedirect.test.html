getSafeRedirectTarget() — ?redirect= validation

js/utils/safeRedirect.js is the one place login/app.js and signup/app.js decide whether a ?redirect= value read back from this app's own address bar is safe to navigate to. Every case here runs with the real page location patched to /pages/login.html first (history.replaceState, not a mock) so resolution behaves exactly as it would on the real page — the same reasoning tests/authRedirectPaths.test.html uses for requireAuth()'s redirect strings.
