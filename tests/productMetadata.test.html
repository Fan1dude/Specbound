Milestone 23 — productMetadata.js client wrapper

Covers the friendly-fallback rework: malformed URLs are rejected client-side (never spending a network round trip or a rate-limit slot), edge-function reason codes map to safe messages — a couple specific enough to help ("unsupported", "invalid"), the rest a single generic fallback that never leaks raw Supabase/networking/ SSRF details — and a successful response always normalizes missing fields to null, never 0 or false.
