Findings 03/04 — BlueprintCard renders real progress/status

Before this fix, every builds-list repository query returned raw `builds` rows with no progress column at all — BlueprintCard's clampProgress(build.progress) always fell back to 0 no matter what actually happened. This confirms the denormalized builds.progress column (0042) renders correctly once populated, across every canonical status plus the legacy "building" read alias, and that Completed/100 consistency shows up correctly on the card. BlueprintCard.js's own imports (escapeHtml, formatCategory, icon, specifications) are all pure/self-contained, so the real file is imported directly — no mocking needed.
