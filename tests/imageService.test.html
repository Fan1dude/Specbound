imageService.js — avatar/gallery decode + processing pipeline

Regression coverage for the production defect where CSP's img-src (missing blob:) silently blocked js/services/imageService.js's loadImage() from ever decoding a locally-selected file — before the fix, every avatar and gallery upload failed with "That file could not be read as an image.", valid files included. Exercises the REAL imageService.js functions (only supabase.storage is mocked) against real, browser-generated JPEG/PNG/WebP image bytes — not fixtures that merely claim to be images — so a regression in the actual decode/canvas pipeline would be caught here, not just a CSP header check.
