Milestone 25 — notificationRepository.js: enrichNotifications()

Exercises the REAL enrichNotifications() implementation (not a pass-through mock, unlike notificationBell.test.html/ notifications.test.html/mobileAccountMenu.test.html, which all stub this function out entirely). Only its two collaborators — getProfilesByIds()/getBuildsByIds() — and the supabase client are mocked at the module boundary, same convention as moderationRepository.test.html. Covers the fix for a real bug found during Milestone 25's live verification: a null build_id (always true for report_resolved and follow notifications) reaching getBuildsByIds()'s unfiltered .in("id", ids) call, which Postgres rejects (22P02: invalid input syntax for type uuid: "null"), breaking the notification bell/page entirely for the affected user.
