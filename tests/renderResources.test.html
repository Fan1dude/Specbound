Finding 05 — public renderResources.js URL-scheme validation

Launch Readiness Audit Finding 05: resource.url went straight into href via escapeAttribute() alone, with no scheme check — a stored javascript:/data: URL would become a live, clickable link. isSafeHttpUrl() (js/utils/safeUrl.js, the same canonical check renderSpecifications.js already routes its own link-shaped values through) is now required before a resource renders as a link at all. An unsafe or absent-but-truthy-checked URL never hides the resource entirely — its label still renders as plain text.
