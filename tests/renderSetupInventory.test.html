Milestone 23 polish — public Setup Inventory product-link overflow fix

Regression coverage for the exact bug reported in live manual testing: a real, very long IKEA product URL (tracking parameters and all) rendered as the visible, clickable product name, producing one long unbroken line that overflowed its card. The product name and the outbound link are now two separate elements — the link's visible label is always the fixed string "View product", never the URL — and both the title and source name get defensive wrap CSS regardless.
