renderExternalLink() — affiliate link disclosure

Covers js/utils/affiliateLink.js — the one shared way any future Specbound-controlled affiliate link should be rendered. isAffiliate must be an explicit, per-call opt-in: this file never marks a link as affiliate by inspecting its URL, since Specbound also contains ordinary user-submitted Amazon links (resources, setup-inventory product links) that are not under Specbound's control and must never be labeled as if they were.
