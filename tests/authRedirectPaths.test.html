Hotfix — requireAuth() redirect path resolution

Standalone from feedbackQueue.test.html / moderationQueue.test.html / myFeedback.test.html (which each prove the exact string passed to their own requireAuth() mock). This file instead proves what that string actually *resolves to* in a real browser, for every requireAuth() call site in the repo, against both a local-dev-style origin and a production-style origin — the exact class of mistake this hotfix fixes (a relative path that resolves correctly at one page depth but not another) can only be caught by resolving against the real serving URL, not by reading the literal string in isolation.
