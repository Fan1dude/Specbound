27A PR5 a11y/perf fixes

Covers findings from the Milestone 27A PR5 accessibility/performance audit (2026-08-15): the Sign In page's "Forgot password?" link measured 17px tall in production, below the WCAG 2.5.8 AA 24px touch-target minimum (flagged by Lighthouse's target-size audit); <nav id="navbar">/<footer id="footer"> ship empty in every page's raw HTML, populated later by loadNavbar()/loadFooter() (js/core/layout.js), contributing ~0.2-0.3 CLS on several pages because nothing reserved their eventual height; and two WCAG 2.5.3 (Label in Name) mismatches where a control's visible text isn't part of its accessible name (BlueprintCard's stage badge, the build page's like count) — flagged by Lighthouse's accessibility audit as label-content-name-mismatch on the production Explore/Build pages.

Also covers two findings from the PR #27 review (2026-08-15): the first version of the touch-target fix above padded the "Forgot password?" link with a negative margin that put its hit-area 4px into the password field's own box; and the skip-link (css/base/reset.css) shared the navbar's z-index, so the navbar — inserted later in <body> — painted over it whenever it was focused, hiding it from sighted keyboard users and intercepting pointer clicks meant for it.
